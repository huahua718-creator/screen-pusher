# 🖥️ 班務大屏傳屏助手 (Screen Pusher - 個人專屬版)

> 專為教學與智慧教室設計的免安裝、跨平台大屏多功能無線互動系統！  
> 支援 **雙向 P2P 檔案傳輸**、**外部網址/YouTube 投放**、**作業多圖/PDF 講義翻頁與縮放**、**手機無線實物鏡頭** 與 **雙向即時白板標註**。

## ✨ 系統特點

* 🚀 **開箱即用**：內建專屬雲端信令通道，開啟網頁即可立即連線使用，無須額外設定金鑰。
* 📱 **零安裝、全相容**：手機（iOS / Android）免下載 App，瀏覽器掃描大屏動態生成的 QR Code 或輸入 6 位數 PIN 碼即可快速配對。
* ⚡ **WebRTC P2P 端到端直連**：影音串流與檔案傳輸均採點對點直連，速度極快、不耗費伺服器儲存空間。
* 🔒 **極致隱私保護**：傳輸的檔案僅存於接收端瀏覽器的執行記憶體（RAM），關閉分頁或重整頁面即自動銷毀，不留硬碟殘存垃圾。

## 🎯 功能特色詳解

### 1. 📁 雙向 P2P 檔案傳輸中心（支援複數檔案）
* **雙向自由互傳**：
  * **手機 ➔ 大屏**：支援單次選取多個檔案，手機點擊發送，大屏端即時彈出 Toast 通知與未讀紅點 Badge。
  * **大屏 ➔ 手機**：點擊大屏左下角懸浮按鈕展開傳輸中心，可直接選取大屏本機檔案推送到手機端下載。
* **支援多格式與大容量**：支援照片、影片、PDF、Word/Excel、簡報、ZIP 壓縮檔等所有格式。
* **分塊傳輸與背壓控制**：內建 64KB Chunk 分塊與 8MB 記憶體背壓保護機制，單檔建議 100MB 內、批次建議 300MB 內，保障行動裝置順暢不閃退。
* **便捷下載**：提供每筆檔案個別下載與一鍵「📦 全部下載」功能。

### 2. 🌐 網頁雙向即時推送（手機 ⇄ 大屏）
* **手機 ➔ 大屏**：輸入任意網址、線上互動測驗（如 Kahoot、Google 表單）或 YouTube 影片，大屏端即時全螢幕呈現。
* **大屏 ➔ 手機（最新）**：
  * **一鍵分享當前網頁**：大屏端正在展示教學網頁或講義時，大屏工具列或左下角「🌐 網頁推送」選單點擊「📲 一鍵推送此網頁至手機端」，即可即時廣播推送到所有已連線的手機端。
  * **自訂網址推送與載入**：大屏端亦可輸入任何網址直接推送至手機端，或於大屏本機全螢幕載入。
* **手機端即時通知與開啟**：
  * 手機端收到大屏網頁時，自動彈出 Toast 提示與卡片，支援「🔗 一鍵在新分頁開啟」與「📋 複製連結」。
  * 自動儲存至歷史推送紀錄，方便日後隨時查閱。

### 3. 🖼️ 多圖與 PDF 課件投影（支援即時翻頁與縮放）
* 支援一次推送多張學生作業照片或多頁 PDF 簡報。
* 手機遙控端與大屏端均提供同步翻頁列（上一頁 / 下一頁 / 頁碼指示器）。
* 大屏端提供「🖐️ 移動」與「🔍 縮放」手勢，支援雙指縮放或滑鼠滾輪放大檢查作業細節。

### 4. 🎥 手機無線實物鏡頭實況投影
* 手機秒變無線實物投影機，桌面實驗、學生書寫或課堂示範即時全螢幕鏡頭投影。
* 支援切換前後鏡頭，以及實況畫面上隨手「📷 拍照推送」至大屏進行凍結講評。

### 5. ✏️ 大屏 & 手機雙向同步手繪白板
* 雙向筆跡即時同步：手機手繪，大屏即時繪出；大屏觸控繪製，手機端同步更新。
* 支援多種色彩切換、橡皮擦、一鍵清除筆跡。
* 筆跡可直接繪製疊加於底層的相片、PDF 講義或網頁上方進行重點批註。

### 6. ⏹️ 遠端一鍵結束與待機重設
* 手機遙控端隨時點擊「⏹️ 結束大屏投放」，大屏端立即乾淨回到待機 QR Code 畫面。

## 🚀 快速上手使用步驟

1. **開啟大屏接收端**：
   * 在教室觸控大屏或電腦瀏覽器開啟 `screen.html`。
   * 螢幕中央會顯示專屬的 **6 位數房間 PIN 碼** 與動態 **QR Code**。
2. **手機連線遙控**：
   * 手機開啟相機掃描 QR Code（或開啟 `mobile.html` 輸入相同的 PIN 碼）。
3. **選擇功能開始互動**：
   * **網址推送**：貼上連結點擊推送。
   * **媒體與鏡頭**：上傳多張照片/PDF 或開啟實物鏡頭。
   * **畫筆標註**：手機全螢幕手繪，大屏即時出筆。
   * **檔案傳輸**：切換至「📁 檔案傳輸」分頁，即可與大屏雙向互傳多個檔案。

## 💡 注意事項

* **檔案保存提醒**：點對點傳輸接收的檔案存放在瀏覽器暫存記憶體（Blob），如需長期保存請務必點擊 **「📥 下載」** 存入裝置硬碟。重新整理或關閉分頁後記憶體暫存會自動釋放。
* **保持頁面活躍**：在進行大檔案傳輸時，請保持手機遙控端頁面開啟在前台，避免切換應用程式或鎖定螢幕導致瀏覽器休眠中斷連線。
